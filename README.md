# 🍻 Brighton Pubfinder

Find your next favourite pub.

Brighton Pubfinder is a social pub discovery platform
designed to help people discover Brighton & Hove's
best pubs, beer gardens, nightlife and hidden gems.

## Features

- Discover local pubs
- Search by location and facilities
- Explore pub events
- Find beer gardens
- Save favourite pubs
